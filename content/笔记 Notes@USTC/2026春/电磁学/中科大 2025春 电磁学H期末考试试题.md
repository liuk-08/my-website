## 1. **环形电流磁场**  

   一电阻率和粗细均匀导体圆环半径为 $R$，以环心建立极坐标在 $\theta=0$ 位置，用直导线从无穷远处沿径向引入电流 $I$，并在 $\theta=\theta_0$ 位置，用另一根直导线从环上将电流沿径向引向无穷远处。求环心处磁感应强度。

【解答】两根直导线在环心显然不产生磁场。考虑圆环上的电流，两侧的电阻之比为 $\theta_0:(2\pi-\theta_0)$，则电流之比为 $(2\pi-\theta_0):\theta_0$。又由于两边的长度之比恰好是 $\theta_0:(2\pi-\theta_0)$，所以两边产生的磁场大小恰好相等，而方向相反，则环心处没有磁场。

   
## 2. **磁介质中的磁场**  

   空间中有一导体空心圆筒半径 $R$，周围的空间被分为三块，绝对磁导率分别为 $\mu_1,\mu_2,\mu_3$，且相对圆心的张角分别为 $\theta_1,\theta_2,\theta_3$，现在在圆筒上沿轴向通电流 $I$。  
   (a) 求三个介质内的磁感应强度和磁场强度分布。  
   (b) 求圆筒表面各个区域的自由电流和磁化电流分布。

【解答】

**(a)** 由于磁感应强度在分界面上的法向连续性，三个介质中的磁感应强度相同为 $B$，根据磁场强度的环路定理有：
$$\oint \vec{H}\cdot d\vec{l} = \left(\frac{\theta_1}{\mu_1}+\frac{\theta_2}{\mu_2}+\frac{\theta_3}{\mu_3}\right)Br = I$$
$$\Rightarrow\quad B = \frac{I}{\left(\dfrac{\theta_1}{\mu_1}+\dfrac{\theta_2}{\mu_2}+\dfrac{\theta_3}{\mu_3}\right)r}$$
各个区域的磁场强度也容易求出
$$H_i = \frac{B}{\mu_i} = \frac{\dfrac{1}{\mu_i}I}{\left(\dfrac{\theta_1}{\mu_1}+\dfrac{\theta_2}{\mu_2}+\dfrac{\theta_3}{\mu_3}\right)r}$$

**(b)** 自由电流分布可通过磁场强度的边值关系 $\vec{i}_0=\hat n\times(\vec{H}_2-\vec{H}_1)$ 求出。在圆筒表面，由于筒内部无磁场，有
$$\vec i_{0_i} = \hat r\times (\vec H_i(r=R)-0) = \frac{\dfrac{1}{\mu_i}I}{\left(\dfrac{\theta_1}{\mu_1}+\dfrac{\theta_2}{\mu_2}+\dfrac{\theta_3}{\mu_3}\right)R}\hat z$$
要求磁化电流，先求磁化强度
$$\vec{M}_i = \frac{\mu_i-\mu_0}{\mu_0}\vec{H}_i = \frac{\left(\dfrac{1}{\mu_0}-\dfrac{1}{\mu_i}\right)I}{\left(\dfrac{\theta_1}{\mu_1}+\dfrac{\theta_2}{\mu_2}+\dfrac{\theta_3}{\mu_3}\right)r}\,\hat z$$
则根据 $\vec{i}'=\hat{n}\times(\vec{M}_2-\vec{M}_1)$，磁化电流面密度为
$$\vec i_i' =\hat r\times(\vec M_i(r=R)-0) = \frac{\left(\dfrac{1}{\mu_0}-\dfrac{1}{\mu_i}\right)I}{\left(\dfrac{\theta_1}{\mu_1}+\dfrac{\theta_2}{\mu_2}+\dfrac{\theta_3}{\mu_3}\right)R}\hat z$$


## 3. **同轴电缆自感与涡旋电场**  
   真空中的同轴电缆，内外半径分别为 $a,b$ 且为薄圆筒。  
   (a) 向内外圆筒中分别输入方向相反电流 $I$，求空间中磁感应强度分布以及同轴电缆的单位长度自感。  
   (b) 现在把电流改为一个随时间变化的电流，变化率恒定为 $k$，已知半径 $r=a$ 处涡旋电场强度为 $E_a$，求涡旋电场。

【解答】

**(a)** 磁感应强度
$$B(r)=\begin{cases}0 & r<a \\\dfrac{\mu_0 I}{2\pi r} & a<r<b \\0 & r>b\end{cases}$$
电感$$L = \frac{\displaystyle\int_a^b \frac{\mu_0 I}{2\pi r}l\,\mathrm dr}{I} = \frac{\mu_0l}{2\pi}\ln\frac{b}{a}$$
单位长度电感
$$L_0=\frac{L}{l}=\frac{\mu_0}{2\pi}\ln \frac ba$$

**(b)** 由于 $r<a$ 内部无磁场，因此电场无散无旋，又由于边界上为恒定值 $E_a$，则内部电场为恒定值 $E=E_a$，同理外部也是匀强电场 $E=E_b$。考虑两个筒之间的部分，做一个纵截面内的长方形环路，从 $a$ 到 $r$，长度为 $l$，列涡旋电场的环路定理 $\oint\vec{E}\cdot d\vec{l} = -\oint\frac{\partial}{\partial t}\vec{B}\cdot d\vec{S}$，有
$$El - E_a l = \int_a^r \frac{\partial}{\partial t}B(r')\,l\,dr' = \frac{\mu_0 k l}{2\pi}\ln\frac{r}{a}$$
$$\Rightarrow\quad E(r) = E_a + \frac{\mu_0 k}{2\pi}\ln\frac{r}{a}$$
代入 $r=b$ 可以算出 $E_b = E_a + \dfrac{\mu_0 k}{2\pi}\ln\frac{b}{a}$，这也就是外部的匀强电场的场强。

## 4. **球面经线圈的电磁场**  

   在一个球面上均匀地布置 $N\gg 1$ 个经线圈导线，现在北极点发出电流 $I$，流过这些经线后在南极汇合。设 $A,B$ 两点在赤道面上，分别距离球心 $a,b$。  
   (a) 求 $A,B$ 两点的位移电流密度。  
   (b) 求 $A,B$ 两点的磁场。  
   (c) 设 $t=0$ 时刻南北极都没有净电荷且电流恒定，求任意时刻 $A,B$ 两点的能量密度和能流密度。

【解答】

**(a)** 由于北极点总是流出电流，南极点总是流入电流，两个极点都有电荷的积累。设南极点的积累电荷为 $Q=Q(t)$，则有 $I=\dfrac{dQ}{dt}$。则 $A,B$ 两点的位移电流是由于南北极点在场点产生的电场随时间变化导致。先求 $A,B$ 点电场

$$\vec{E}_A = \frac{1}{4\pi\varepsilon_0}\frac{2QR}{(R^2+a^2)^{3/2}}\,\hat z,\qquad\vec{E}_B = \frac{1}{4\pi\varepsilon_0}\frac{2QR}{(R^2+b^2)^{3/2}}\,\hat z$$
则位移电流密度为
$$\vec{j}_D(A) = \varepsilon_0\frac{\partial}{\partial t}\vec{E}_A = \frac{1}{4\pi}\frac{2IR}{(R^2+a^2)^{3/2}}\,\hat z$$
$$\vec{j}_D(B) = \varepsilon_0\frac{\partial}{\partial t}\vec{E}_B = \frac{1}{4\pi}\frac{2IR}{(R^2+b^2)^{3/2}}\,\hat z$$

**(b)** 求磁场用全电流安培环路定理 $\oint\vec{B}\cdot d\vec{l} = \mu_0\iint(\vec{j}_0+\vec{j}_D)\cdot d\vec{S}$。  
对于 $A$ 点，取半径 $a$ 的环路，中间没有传导电流，故只要计算位移电流的通量
$$2\pi a B_A = \mu_0\int_0^a \frac{1}{4\pi}\frac{2IR}{(R^2+r^2)^{3/2}}\,2\pi r\,dr = \mu_0 I\left(1-\frac{R}{\sqrt{R^2+a^2}}\right)$$
$$\Rightarrow\quad B_A = \frac{\mu_0 I}{2\pi a}\left(1-\frac{R}{\sqrt{R^2+a^2}}\right)\,\hat \phi$$
$B$ 点同理，但是这里传导电流不再为零
$$2\pi b B_B = \mu_0\left(\int_0^b \frac{1}{4\pi}\frac{2IR}{(R^2+r^2)^{3/2}}\,2\pi r\,dr - I\right) = -\mu_0 I\frac{R}{\sqrt{R^2+b^2}}$$
$$\Rightarrow\quad B_B = -\frac{\mu_0 I}{2\pi b}\frac{R}{\sqrt{R^2+b^2}}\,\hat \phi$$

**(c)** 此时 $Q(t)=It$。计算能量密度
$$w_A = \frac12\varepsilon_0 E_A^2 + \frac{1}{2\mu_0}B_A^2 = \frac{I^2 R^2 t^2}{8\pi^2\varepsilon_0(R^2+a^2)^3} + \frac{\mu_0 I^2}{8\pi^2 a^2}\left(1-\frac{R}{\sqrt{R^2+a^2}}\right)^2$$
$$w_B = \frac12\varepsilon_0 E_B^2 + \frac{1}{2\mu_0}B_B^2 = \frac{I^2 R^2 t^2}{8\pi^2\varepsilon_0(R^2+b^2)^3} + \frac{\mu_0 I^2}{8\pi^2 b^2}\left(\frac{R}{\sqrt{R^2+b^2}}\right)^2$$
计算能流密度（坡印廷矢量）
$$\vec{S}_A = \vec{E}_A \times \frac{1}{\mu_0}\vec{B}_A = -\frac{I^2 R t}{4\pi^2\varepsilon_0(R^2+a^2)^{3/2}}\left(1-\frac{R}{\sqrt{R^2+a^2}}\right)\,\hat r$$
$$\vec{S}_B = \vec{E}_B \times \frac{1}{\mu_0}\vec{B}_B = \frac{I^2 R^2 t}{4\pi^2\varepsilon_0(R^2+b^2)^2}\,\hat r$$

## 5. **含气隙铁芯磁路**  
   两个线圈匝数分别为 $N_1,N_2$，电流分别为 $I_1,I_2$，认为铁芯的相对磁导率 $\mu_r\gg 1$。有两处空气隙，尺寸相同，厚度为 $h$，正对面积为 $S$。  
   (a) 求两处缝隙分别的磁感应强度和磁场强度。  
   (b) 求两个线圈分别的自感以及互感。  
   (c) 求左边缝隙处上下铁芯之间的吸力。


【解答】
 (a) 两处气隙的磁感应强度 B 与磁场强度 H

磁路中 $\mu_r\gg 1$，铁芯磁阻忽略不计。每个气隙的磁阻为$$\mathcal{R}_g = \frac{h}{\mu_0 S}$$
两气隙串联，总磁阻 $$\mathcal{R}_{\text{总}} = 2\mathcal{R}_g = \frac{2h}{\mu_0 S}$$
总磁动势（设绕组方向使磁动势相加） $$\mathcal{E_m} = N_1 I_1 + N_2 I_2$$
磁路中的磁通$$\Phi = \frac{\mathcal{E_m}}{\mathcal{R}_{\text{总}}} = (N_1 I_1 + N_2 I_2) \cdot \frac{\mu_0 S}{2h}$$
两气隙中磁通相同，因此
磁感应强度 $$B_1 = B_2 = \frac{\Phi}{S} = \frac{\mu_0 (N_1 I_1 + N_2 I_2)}{2h}$$
磁场强度$$H_1 = H_2 = \frac{B}{\mu_0} = \frac{N_1 I_1 + N_2 I_2}{2h}$$
(b) 自感和互感

自感 L₁（令 I₂ = 0）$$\Phi_1 = \frac{N_1 I_1 \mu_0 S}{2h},\quad \Psi_{11} = N_1 \Phi_1 = \frac{N_1^2 I_1 \mu_0 S}{2h}\Longrightarrow L_1 = \frac{\Psi_{11}}{I_1} = \frac{N_1^2 \mu_0 S}{2h}$$
同理，$$L_2 = \frac{N_2^2 \mu_0 S}{2h}$$
互感 M（令 I₁ = 1 A，I₂ = 0）磁通 Φ₁ 链过 N₂ 匝线圈$$\Psi_{21} = N_2 \Phi_1 = \frac{N_1 N_2 \mu_0 S}{2h}$$
互感$$M = \frac{\Psi_{21}}{I_1} = \frac{N_1 N_2 \mu_0 S}{2h}$$
由互易性，$$M_{12} = M_{21}= M$$

(c) 左边气隙处上下铁芯之间的吸力

**方法一：静磁压强**

气隙中每个磁极面上的力为$$F = \frac{B^2 S}{2\mu_0}$$代⼊ (a) 的结果 B  $$F = \frac{1}{2\mu_0} \left[ \frac{\mu_0 (N_1 I_1 + N_2 I_2)}{2h} \right]^2 S= \frac{\mu_0 (N_1 I_1 + N_2 I_2)^2 S}{8h^2}$$该力为吸引力，方向垂直于气隙截面，将上下铁芯向中间拉拢。

**方法二：磁荷法**

铁芯端面看成带磁荷的面，面磁荷密度 $\sigma_m = \mu_0 M = B$（因铁芯内 $\mu_r\gg 1$，所以 $H\approx 0$，$B = \mu_0 M$）。  
一面磁荷在另一面处产生的附加磁场 
$$H' = \frac{\sigma_m}{2\mu_0} = \frac{B}{2\mu_0}$$
单位面积受力 
$$f = \sigma_m \cdot H' = \frac{B^2}{2\mu_0}$$
整个面积 $S$ 上总吸力 
$$F = f S = \frac{B^2 S}{2\mu_0} = \frac{\mu_0 S}{8h^2} (N_1 I_1 + N_2 I_2)^2$$

## 6. **介质中的平面电磁波**  
   在相对介电常数、相对磁导率分别为 $\varepsilon_r,\mu_r$ 的介质中有电磁波  
   $$\vec{E}=\vec{E}_0 e^{-i(\omega t-\vec{k}\cdot\vec{r})},\quad \vec{B}=\vec{B}_0 e^{-i(\omega t-\vec{k}\cdot\vec{r})}.$$  
   (a) 证明 $\vec{k}\cdot\vec{E}=0,\ \vec{k}\cdot\vec{B}=0$.  
   (b) 证明 $\sqrt{\varepsilon_0\varepsilon_r}E_0=\dfrac{B_0}{\mu_0\mu_r}$.  
   (c) 证明波速为 $v=\dfrac{c}{n}$，其中 $n=\dfrac{1}{\sqrt{\mu_r\varepsilon_r}}$.  
   (d) 求电磁波的能量密度 $w$ 和能流密度 $\vec{S}$.  
   (e) 证明 $\vec{S}=\dfrac{c}{n}w\,\hat k$，其中 $\hat k=\dfrac{\vec{k}}{k}$ 为波矢方向的单位矢量。

【解答】

**(a)** 由 $\nabla\cdot\vec{E}=0$ 和 $\nabla\cdot\vec{B}=0$ 代入平面波表达式可得 $$\vec{k}\cdot\vec{E}=0,\ \vec{k}\cdot\vec{B}=0$$

**(b)** 由 $\nabla\times\vec{E} = -\dfrac{\partial\vec{B}}{\partial t}$ 代入平面波表达式可得 $\vec{k}\times\vec{E} = \omega\vec{B}$，取模并利用 $\omega/k=v$ 及 $v=1/\sqrt{\mu\varepsilon}$ 可得振幅关系$$\sqrt{\varepsilon_0\varepsilon_r}E_0=\dfrac{B_0}{\mu_0\mu_r}$$
**(c)** 由波动方程可得 $v = \dfrac{1}{\sqrt{\mu_0\mu_r\varepsilon_0\varepsilon_r}} = \dfrac{c}{\sqrt{\mu_r\varepsilon_r}}$，故 $n=\sqrt{\mu_r\varepsilon_r}$。

**(d)** 能量密度 $w = \dfrac12\varepsilon E^2 + \dfrac{1}{2\mu}B^2$，能流密度 $\vec{S} = \vec{E}\times\vec{H}$

**(e)** 利用振幅关系和波速可得 $$\vec{S} = v w\,\hat k = \dfrac{c}{n}w\,\hat k$$
