## 第一题

 (1) 一个半径为 $R$ 的实心导体金属球，用一个平面将球体截成表面积为 $\pi R^2$ 和 $3\pi R^2$ 的两部分 A 和 B，沿着截面法线的方向将两部分错开极小的距离，表面积为 $\pi R^2$ 的部分带上 $+Q$ 的电荷，表面积为 $3\pi R^2$ 的部分不带电，求 A 部分受到的静电力。
 ![[Pasted image 20260705174218.png|296]]
 
 (2) 一个固有磁化的磁介质球壳，内径为 $a$，外径为 $b$，球壳内的磁化强度为 $M$，方向沿 $z$ 轴正方向，求全空间的磁感应强度分布 $\vec{B}(r)$。
![[Fig_2.png|320]]
【解答】

**(1) 求解 A 部分受到的静电力**

设整体实心导体金属球半径为 $R$。由于切割后两部分错开距离极小 ($d \to 0$)，整体对外等效为一完整的等势导体球。电荷 $Q$ 均匀分布在导体球外表面，电荷面密度为
$$\sigma_{out} = \frac{Q}{4\pi R^2}$$
已知 $A$ 的球面面积为 $\pi R^2$，$B$ 的球面面积为 $3\pi R^2$。故外表面所带电荷量分别为
$$Q_{A, out} = \sigma_{out} \cdot \pi R^2 = \frac{1}{4}Q$$
$$Q_{B, out} = \sigma_{out} \cdot 3\pi R^2 = \frac{3}{4}Q$$
题设中 B 部分整体不带电，根据电荷守恒，B 的内截面（切割面）必须带负电荷以抵消外表面电荷
$$Q_{B, in} = -Q_{B, out} = -\frac{3}{4}Q$$
题设 A 部分整体带电 $+Q$，则 A 的内截面所带电荷量为
$$Q_{A, in} = Q - Q_{A, out} = Q - \frac{1}{4}Q = \frac{3}{4}Q$$
由于间隙极小，A、B 的两个内截面构成了一个带等量异号电荷的平行板电容器。根据球冠面积公式 $S_A = 2\pi R h = \pi R^2$，可得截面高度 $h = R/2$。截面圆的半径 $r_c$ 为
$$r_c = \sqrt{R^2 - (R/2)^2} = \frac{\sqrt{3}}{2}R$$
截面面积 $S_c = \pi r_c^2 = \frac{3}{4}\pi R^2$。截面上的电荷面密度大小为
$$\sigma_c = \frac{Q_{A, in}}{S_c} = \frac{3Q/4}{3\pi R^2/4} = \frac{Q}{\pi R^2}$$
根据极板间静电力公式，单位面积受力 $f = \frac{\sigma_c^2}{2\varepsilon_0}$，A 截面受到的总静电力为
$$F = f \cdot S_c = \frac{1}{2\varepsilon_0} \left( \frac{Q}{\pi R^2} \right)^2 \left( \frac{3}{4}\pi R^2 \right) = \frac{3Q^2}{8\pi \varepsilon_0 R^2}$$
**结论:** A 部分受到的静电力大小为 $\frac{3Q^2}{8\pi \varepsilon_0 R^2}$，方向为垂直于截面指向 B（吸引力）。

**(2) 求解磁介质球壳全空间的磁感应强度**

固有磁化强度为 $\vec{M} = M\hat{z}$。由于磁化均匀，体束缚磁荷密度 $\rho_m = -\nabla \cdot \vec{M} = 0$。
内外表面的面束缚磁荷密度分别为：
内表面 ($r=a$): $\sigma_{ma} = \vec{M} \cdot (-\hat{r}) = -M\cos\theta$
外表面 ($r=b$): $\sigma_{mb} = \vec{M} \cdot \hat{r} = M\cos\theta$
利用态叠加原理，此系统等效为两个均匀磁化的实心球的叠加：
1. 半径为 $b$，磁化强度为 $\vec{M}$ 的实心球 $b$。
2. 半径为 $a$，磁化强度为 $-\vec{M}$ 的实心球 $a$。
已知半径为 $R$、磁化强度为 $\vec{M}_0$ 的均匀磁化球的磁场分布为：
内部: $\vec{B}_{in} = \frac{2}{3}\mu_0\vec{M}_0$
外部: $\vec{B}_{out}(\vec{r}) = \frac{\mu_0}{4\pi r^3} [3(\vec{m} \cdot \hat{r})\hat{r} - \vec{m}]$，其中磁矩 $\vec{m} = \frac{4}{3}\pi R^3 \vec{M}_0$。

分三个空间区域叠加：
**区域 I ($r < a$) - 球壳空腔内:**
处于球 $a$ 与球 $b$ 的内部。
$$\vec{B}_I = \vec{B}_{in, b} + \vec{B}_{in, a} = \frac{2}{3}\mu_0\vec{M} + \frac{2}{3}\mu_0(-\vec{M}) = 0$$

**区域 II ($a \le r < b$) - 介质层内:**
处于球 $b$ 内部，球 $a$ 外部。球 $a$ 的等效磁矩为 $\vec{m}_a = -\frac{4}{3}\pi a^3 \vec{M}$。
$$\vec{B}_{II}(\vec{r}) = \frac{2}{3}\mu_0\vec{M} + \frac{\mu_0}{4\pi r^3} \left[ 3(\vec{m}_a \cdot \hat{r})\hat{r} - \vec{m}_a \right] = \frac{2}{3}\mu_0\vec{M} - \frac{\mu_0 a^3}{3r^3} \left[ 3(\vec{M} \cdot \hat{r})\hat{r} - \vec{M} \right]$$

**区域 III ($r \ge b$) - 球壳外部:**
处于球 $a$ 和球 $b$ 的外部。总等效磁矩 $\vec{m}_{total} = \vec{m}_b + \vec{m}_a = \frac{4}{3}\pi (b^3 - a^3) \vec{M}$。
$$\vec{B}_{III}(\vec{r}) = \frac{\mu_0(b^3 - a^3)}{3r^3} \left[ 3(\vec{M} \cdot \hat{r})\hat{r} - \vec{M} \right]$$

## 第二题

(1) 无限大导体平面上方 $d$ 处，有一个电偶极子，电偶极子方向与导体平面法向夹角为 $\theta$，求电偶极子的受力和力矩。
![[Fig_3.png|242]]
(2) 为了探究磁铁之间的相互作用力，做以下实验，两个相同的磁铁 A 和 B，磁铁 A 悬挂在长为 $l=1m$ 的绳子上，用另一个磁铁 B 缓慢靠近，并时刻保持磁铁 A 和磁铁 B 在同一高度，且轴在同一直线上，当磁铁 A 水平方向移动 $x_1=1cm$，且两个磁铁之间的距离 $d_1=4cm$ 时，磁铁 A 的平衡开始被破坏，并迅速被吸引，已知 $F_m \propto d^{-n}$，求 $n$。
![[Fig_4.png|409]]
【解答】

**(1) 电偶极子受力和力矩**

设定无限大导体平面为 $z=0$ 平面。原电偶极子位于 $(0,0,d)$，其极矩向量为 $\vec{p} = p\sin\theta\hat{x} + p\cos\theta\hat{z}$。
根据镜像法，在 $z=-d$ 处存在一镜像偶极子，其极矩为 $\vec{p}' = -p\sin\theta\hat{x} + p\cos\theta\hat{z}$。
镜像偶极子在原偶极子处（相对镜像偶极子的位矢为 $\vec{r} = 2d\hat{z}$）产生的电场为：
$$\vec{E}' = \frac{1}{4\pi\varepsilon_0 (2d)^3} \left[ 3(\vec{p}' \cdot \hat{z})\hat{z} - \vec{p}' \right]$$
代入 $\vec{p}'$:
$$\vec{E}' = \frac{1}{32\pi\varepsilon_0 d^3} \left[ 3(p\cos\theta)\hat{z} - (-p\sin\theta\hat{x} + p\cos\theta\hat{z}) \right] = \frac{1}{32\pi\varepsilon_0 d^3} (p\sin\theta\hat{x} + 2p\cos\theta\hat{z})$$
原偶极子在非均匀电场中的静电势能为 $U = -\frac{1}{2} \vec{p} \cdot \vec{E}'$ （系数 1/2 来自系统内部作用）：
$$U = -\frac{1}{64\pi\varepsilon_0 d^3} (p^2\sin^2\theta + 2p^2\cos^2\theta) = -\frac{p^2 (1+\cos^2\theta)}{64\pi\varepsilon_0 d^3}$$
受力（由于对称性仅在 z 方向有受力）：
$$\vec{F} = -\nabla U = -\frac{\partial U}{\partial d} \hat{z} = -\frac{3p^2(1+\cos^2\theta)}{64\pi\varepsilon_0 d^4} \hat{z}$$
（方向垂直导体平面向下，即受到吸引力）
力矩:
$$\vec{\tau} = \vec{p} \times \vec{E}' = (p\sin\theta\hat{x} + p\cos\theta\hat{z}) \times \frac{p}{32\pi\varepsilon_0 d^3} (\sin\theta\hat{x} + 2\cos\theta\hat{z})$$
利用 $\hat{x}\times\hat{z}=-\hat{y}$ 及 $\hat{z}\times\hat{x}=\hat{y}$ 展开：
$$\vec{\tau} = \frac{p^2}{32\pi\varepsilon_0 d^3} (2\sin\theta\cos\theta (-\hat{y}) + \cos\theta\sin\theta \hat{y}) = -\frac{p^2 \sin\theta \cos\theta}{32\pi\varepsilon_0 d^3} \hat{y}$$

**(2) 探究磁铁间相互作用力的指数 $n$**

磁力模型为 $F_m = \frac{k}{d^n}$。
磁铁 A 水平移动 $x$ 时，单摆提供的重力水平回复力为 $F_r = mg \tan\phi \approx mg \frac{x}{l}$ （微小位移近似）。
系统处于平衡状态时：$F_m = F_r$。
实验中缓慢移动 B，A 与 B 之间的实际距离 $d$ 与 A 的位移 $x$ 相关。当到达临界点时，平衡被破坏，意味着磁力的空间增长率超过了机械回复力的空间增长率。临界失稳条件为：
$$\frac{\partial F_r}{\partial x} = \left| \frac{\partial F_m}{\partial x} \right|$$
在 B 固定的某一瞬时微扰动下，间距增量 $\Delta d = -\Delta x$。故对于 A 的坐标求导有：
$$\frac{mg}{l} = \frac{\partial}{\partial x} \left( \frac{k}{d^n} \right) = \frac{\partial}{\partial d} \left( \frac{k}{d^n} \right) \cdot \frac{\partial d}{\partial x} = \left( -n \frac{k}{d^{n+1}} \right)(-1) = n \frac{k}{d^{n+1}}$$
结合临界平衡等式 $\frac{k}{d^n} = mg \frac{x}{l}$，两式相除：
$$\frac{x}{1} = \frac{d}{n} \implies n = \frac{d}{x}$$
代入题目给定的临界状态值：$x_1 = 1\text{ cm}$, $d_1 = 4\text{ cm}$。
$$n = \frac{4}{1} = 4$$

## 第三题

一个内径为 $R_1=R$，外径为 $R_2=2R$ 的不带电导体球壳，在过球心的一条直线上放置两个点电荷，一个点电荷电量 $q_1=q$，到球心的距离为 $d_1=\frac{R}{2}$ 另一个点电荷电量 $q_2=q$，到球心的距离为 $d_2=(\sqrt{5}+1)R$。
(1) 求点电荷 $q_1$ 和 $q_2$ 的受力 $F_1$ 和 $F_2$；
(2) 求球壳的电势 $V$ 和球心处的电势 $V_0$；
(3) 分别求导体球壳内表面上电荷的自能和导体球壳内表面上电荷与点电荷 $q_1$ 之间的相互作用能；
(4) 分别求导体球壳外表面上电荷的自能和导体球壳外表面上电荷与点电荷之间的相互作用能；
(5) 保持导体电荷不带电，求将点电荷 $q_2$ 极其缓慢地移动至无穷远处时克服静电力的外力所做的功；
(6) 保持导体电势为 (2) 中所求的 $V$ 不变，求将点电荷 $q_2$ 极其缓慢地移动至无穷远处时克服静电力的外力所做的功。
![[Fig_5.png|363]]
【解答】

**前置分析与镜像电荷**
由于球壳不带电且处于静电平衡，内表面和外表面的感应电荷被壳层体完全隔离（静电屏蔽）。
* **针对 $q_1$：** 在内表面（$r=R$）感应出电荷，总量为 $-q$。该边界问题可通过在壳内引入镜像电荷 $q_1'$ 求解。位置 $r_1' = \frac{R^2}{d_1} = 2R$，电量 $q_1' = -\frac{R}{d_1} q = -2q$。
* **针对 $q_2$：** $q_1$ 的存在使得外表面（$r=2R$）必须带 $+q$ 的电荷，以满足球壳总体不带电的条件。$q_2$ 与外表面 $+q$ 相互作用，可利用镜像电荷法。$q_2$ 诱导的镜像电荷 $q_2' = -\frac{2R}{d_2}q$，位于 $r_2' = \frac{(2R)^2}{d_2} = \frac{4R^2}{d_2}$。为了保证外表面总电荷量为 $+q$，需在球心处放置补偿电荷 $q_c = q - q_2' = q + \frac{2R}{d_2}q$。

代入 $d_2 = (\sqrt{5}+1)R$：
* $q_2' = -\frac{2R}{(\sqrt{5}+1)R}q = -\frac{\sqrt{5}-1}{2}q$
* $r_2' = \frac{4R^2}{(\sqrt{5}+1)R} = (\sqrt{5}-1)R$
* $q_c = q - \left(-\frac{\sqrt{5}-1}{2}q\right) = \frac{\sqrt{5}+1}{2}q$

**(1) 求点电荷受力**
* **$F_1$：** $q_1$ 仅受内表面感应电荷作用，等效为受到 $q_1'$ 的力。
    $$F_1 = \frac{1}{4\pi\varepsilon_0} \frac{q_1 q_1'}{(r_1' - d_1)^2} = \frac{1}{4\pi\varepsilon_0} \frac{q(-2q)}{(2R - R/2)^2} = -\frac{8q^2}{9\pi\varepsilon_0 R^2} \text{ (负号表示指向球心)}$$
* **$F_2$：** $q_2$ 受 $q_2'$ 和 $q_c$ 的共同作用。$q_2$ 与 $q_2'$ 的距离为 $d_2 - r_2' = (\sqrt{5}+1)R - (\sqrt{5}-1)R = 2R$。
    $$F_2 = \frac{q_2}{4\pi\varepsilon_0} \left( \frac{q_2'}{(d_2 - r_2')^2} + \frac{q_c}{d_2^2} \right) = \frac{q}{4\pi\varepsilon_0} \left( \frac{-\frac{\sqrt{5}-1}{2}q}{(2R)^2} + \frac{\frac{\sqrt{5}+1}{2}q}{((\sqrt{5}+1)R)^2} \right)$$
    右侧第二项化简：$\frac{(\sqrt{5}+1)q/2}{(6+2\sqrt{5})R^2} = \frac{q}{2(\sqrt{5}+1)R^2} \cdot \frac{\sqrt{5}-1}{\sqrt{5}-1} = \frac{(\sqrt{5}-1)q}{8R^2}$
    左侧第一项化简：$\frac{-\frac{\sqrt{5}-1}{2}q}{4R^2} = -\frac{(\sqrt{5}-1)q}{8R^2}$
    两项相加，得 $F_2 = 0$。

**(2) 求电势 $V$ 和 $V_0$**
* **球壳电势 $V$：** 球壳是等势体。在 $r \ge 2R$ 外部空间，电势表现为点电荷 $q_2$ 以及外表面等效系统 ($q_2'$ 和 $q_c$) 的叠加。在 $r=2R$ 处，$\Phi_{q2} + \Phi_{q2'} = 0$，故表面电势仅由补偿电荷 $q_c$ 决定。
    $$V = \frac{q_c}{4\pi\varepsilon_0 (2R)} = \frac{\frac{\sqrt{5}+1}{2}q}{8\pi\varepsilon_0 R} = \frac{(\sqrt{5}+1)q}{16\pi\varepsilon_0 R}$$
* **球心电势 $V_0$：** 叠加原理 $V_0 = \Phi_{q1}(0) + \Phi_{in\_surf}(0) + \Phi_{out\_surf}(0) + \Phi_{q2}(0)$。内表面和外表面电荷到球心距离固定分别为 $R$ 和 $2R$。
    $$V_0 = \frac{q}{4\pi\varepsilon_0 (R/2)} + \frac{-q}{4\pi\varepsilon_0 R} + \frac{+q}{4\pi\varepsilon_0 (2R)} + \frac{q}{4\pi\varepsilon_0 (\sqrt{5}+1)R}$$
    $$V_0 = \frac{q}{4\pi\varepsilon_0 R} \left( 2 - 1 + \frac{1}{2} + \frac{1}{\sqrt{5}+1} \right) = \frac{q}{4\pi\varepsilon_0 R} \left( \frac{3}{2} + \frac{\sqrt{5}-1}{4} \right) = \frac{(5+\sqrt{5})q}{16\pi\varepsilon_0 R}$$

**(3) 内表面相互作用能与自能**
* **相互作用能 $W_{int, in}$：** 利用 $\Phi_{in\_surf}(\vec{r})$ 在球空腔内精确等于 $\Phi_{q1'}(\vec{r})$。
    $$W_{int, in} = \int \rho_1 \Phi_{in\_surf} dV = q_1 \Phi_{q1'}(r=R/2) = q \left[ \frac{-2q}{4\pi\varepsilon_0 (2R - R/2)} \right] = -\frac{q^2}{3\pi\varepsilon_0 R}$$
* **自能 $W_{self, in}$：** 将 $q_1$ 从原点移至 $R/2$ 的静电力作功为系统内部装配能 $W_{assm} = W_{self, in} + W_{int, in}$。
    $W_{assm} = \int_0^q \Phi_{ind}(location) dq' = \int_0^q \frac{q' \cdot (-2)}{4\pi\varepsilon_0 (3R/2)} dq' = -\frac{q^2}{6\pi\varepsilon_0 R}$。
    $$W_{self, in} = W_{assm} - W_{int, in} = -\frac{q^2}{6\pi\varepsilon_0 R} - \left( -\frac{q^2}{3\pi\varepsilon_0 R} \right) = \frac{q^2}{6\pi\varepsilon_0 R}$$

**(4) 外表面相互作用能与自能**
* **相互作用能 $W_{int, out}$：**
    $$W_{int, out} = q_2 \Phi_{out\_surf}(d_2) = q_2 \left[ \frac{q_2'}{4\pi\varepsilon_0 (d_2 - r_2')} + \frac{q_c}{4\pi\varepsilon_0 d_2} \right]$$
    $$W_{int, out} = \frac{q}{4\pi\varepsilon_0} \left[ \frac{-\frac{\sqrt{5}-1}{2}q}{2R} + \frac{\frac{\sqrt{5}+1}{2}q}{(\sqrt{5}+1)R} \right] = \frac{q^2}{4\pi\varepsilon_0 R} \left( -\frac{\sqrt{5}-1}{4} + \frac{1}{2} \right) = \frac{(3-\sqrt{5})q^2}{16\pi\varepsilon_0 R}$$
* **自能 $W_{self, out}$：** 外表面的分布建立在恒定电势 $V$ 上，满足身份式 $W_{self, out} = \frac{1}{2}Q_{total\_out} V - \frac{1}{2} W_{int, out}$。
    $$W_{self, out} = \frac{1}{2} q \left( \frac{(\sqrt{5}+1)q}{16\pi\varepsilon_0 R} \right) - \frac{1}{2} \left( \frac{(3-\sqrt{5})q^2}{16\pi\varepsilon_0 R} \right) = \frac{q^2}{32\pi\varepsilon_0 R} \left( \sqrt{5}+1 - 3 + \sqrt{5} \right) = \frac{(\sqrt{5}-1)q^2}{16\pi\varepsilon_0 R}$$

**(5) 球壳不带电时移动 $q_2$ 至无穷远的做功**
外力做功等于外部静电系统总能量的变化量。当 $q_2$ 移至无穷远时，外表面 $+q$ 电荷均匀分布。
初始外部静电能: $U_{out, i} = W_{self, out} + W_{int, out} = \frac{(\sqrt{5}-1)q^2}{16\pi\varepsilon_0 R} + \frac{(3-\sqrt{5})q^2}{16\pi\varepsilon_0 R} = \frac{2q^2}{16\pi\varepsilon_0 R}$
末态外部静电能 (均匀带电球面): $U_{out, f} = \frac{q^2}{2 \cdot 4\pi\varepsilon_0 (2R)} = \frac{q^2}{16\pi\varepsilon_0 R}$
$$W_{ext} = U_{out, f} - U_{out, i} = -\frac{q^2}{16\pi\varepsilon_0 R}$$

**(6) 球壳恒定电势时移动 $q_2$ 至无穷远的做功**
恒电势代表与外电源连接。为保持 $V = \frac{(\sqrt{5}+1)q}{16\pi\varepsilon_0 R}$ 不变，中心等效补偿电荷 $q_c$ 必须严格保持恒定。
计算外力对抗 $q_2$ 受力的线积分： $F_2'(r) = \frac{q}{4\pi\varepsilon_0} \left[ \frac{-2Rq/r}{(r - 4R^2/r)^2} + \frac{q_c}{r^2} \right]$
$$W_{ext} = \int_{d_2}^\infty (-F_2'(r)) dr = \frac{q}{4\pi\varepsilon_0} \left[ \frac{Rq}{r^2 - 4R^2} - \frac{q_c}{r} \right]_{d_2}^\infty = \frac{q}{4\pi\varepsilon_0} \left( 0 - \left( \frac{Rq}{d_2^2 - 4R^2} - \frac{q_c}{d_2} \right) \right)$$
代入 $d_2^2 - 4R^2 = (2+2\sqrt{5})R^2$ 及前文推导的分式：
$$W_{ext} = -\frac{q}{4\pi\varepsilon_0} \left( \frac{\sqrt{5}-1}{8R}q - \frac{1}{2R}q \right) = \frac{(5-\sqrt{5})q^2}{32\pi\varepsilon_0 R}$$

## 第四题

如图，一导体球壳的两极分别连接上相互平行的两条半无限长直导线，导线中电流大小为 $I$，方向相反。
(1) 求球心点处磁感应强度大小。
(2) 两条直导线所在平面上与极轴方向夹角为 $\theta$ 处对应的球壳表面点 $P$，分别求 $P$ 点处球壳表面内外非常接近球壳表面处的磁感应强度。
![[Fig_6.png]]

【解答】

**(1) 求球心点处磁感应强度大小**
由对称性可知，沿导体球壳经线方向分布的表面电流 $\vec{K}$ 对球心产生的磁场完全抵消 ($\int_{sphere} d\vec{B} = 0$)。
球心的磁场仅由两根半无限长直导线产生。
设上直导线在 $z=R$ 平面上自 $x=-\infty$ 接向 $x=0$，下直导线在 $z=-R$ 平面上自 $x=0$ 接向 $x=-\infty$。
利用毕奥-萨伐尔定律，半无限长导线端点正下/上方距离 $R$ 处的磁场大小为 $B = \frac{\mu_0 I}{4\pi R}$。两导线在球心处激发的磁场方向均沿 $\hat{y}$ 正向（右手法则）
$$B_O = \frac{\mu_0 I}{4\pi R} + \frac{\mu_0 I}{4\pi R} = \frac{\mu_0 I}{2\pi R}$$

**(2) 求 $P$ 点表面内外的磁场**
在极角为 $\theta$ 处，球壳上的面电流密度为 $\vec{K} = \frac{I}{2\pi R\sin\theta} \hat{\theta}$。
由边界条件跃变方程：$\vec{B}_{out} - \vec{B}_{in} = \mu_0 \vec{K} \times \hat{n} = \frac{\mu_0 I}{2\pi R\sin\theta} \hat{\phi}$。
对于球壳内部 ($r \to R^-$)，球面电流不产生磁场分量，仅存在来自外部两根平行导线的磁场 $\vec{B}_{wires}$。
利用毕奥-萨伐尔定律积分两根半无限长直导线在平面内任意点 $(R\sin\theta, 0, R\cos\theta)$ 处的磁场，经积分化简可得
$$\vec{B}_{in} = \vec{B}_{wires} = \frac{\mu_0 I}{4\pi R} \left[ \frac{1-\cos(\theta/2)}{1-\cos\theta} + \frac{1-\sin(\theta/2)}{1+\cos\theta} \right] \hat{y}$$
对于球壳外部 ($r \to R^+$)，由于穿越面电流层，需增加跃变分量
$$\vec{B}_{out} = \vec{B}_{wires} + \frac{\mu_0 I}{2\pi R\sin\theta} \hat{y}$$

## 第五题

超导体的 London 方程，超导体内存在 Cooper 电子对，质量为 $m^*=2m_e$，电荷量为 $e^*=2e$，数密度为 $n_s^*$。
(1) 求证: London 第一方程 $\frac{d\vec{J}_s}{dt}=\frac{n_s^*e^{*2}}{m^*}\vec{E}$
(2) 求证: $\frac{d}{dt}(\nabla\times\vec{J}_s+\frac{n_s^*e^{*2}}{m^*}\vec{B})=0$ 令方程左侧括号内等于 0，可以得到 London 第二方程。
(3) 求证: London 第二方程还可以写成 $\nabla^2\vec{B}=\frac{\vec{B}}{\lambda_L^2}$，并求出 $\lambda_L$。
(4) 考虑 $x>0$ 的半无穷大空间为超导体，$x<0$ 的空间内为均匀磁场 $\vec{B}=B_0\hat{z}$，求超导体内部磁场随 $x$ 的分布 $\vec{B}(x)$。

【解答】

**(1) London 第一方程**
根据 Cooper 电子对在电场中的牛顿第二定律
$$m^* \frac{d\vec{v}}{dt} = e^* \vec{E}$$
超导电流密度定义为 $\vec{J}_s = n_s^* e^* \vec{v}$，对其关于时间求导，得 $$\frac{d\vec{J}_s}{dt} = n_s^* e^* \frac{d\vec{v}}{dt}$$将上式代入牛顿运动方程，得
$$\frac{d\vec{J}_s}{dt} = \frac{n_s^* e^{*2}}{m^*} \vec{E}$$

**(2) London 第二方程雏形**
对方程 (1) 两边取旋度算符 $\nabla \times$
$$\nabla \times \frac{d\vec{J}_s}{dt} = \frac{n_s^* e^{*2}}{m^*} \nabla \times \vec{E}$$
应用法拉第电磁感应定律 $\nabla \times \vec{E} = -\frac{\partial \vec{B}}{\partial t}$，并交换左侧空间与时间微商顺序
$$\frac{d}{dt}(\nabla \times \vec{J}_s) = -\frac{n_s^* e^{*2}}{m^*} \frac{\partial \vec{B}}{\partial t} \implies \frac{d}{dt} \left( \nabla \times \vec{J}_s + \frac{n_s^* e^{*2}}{m^*} \vec{B} \right) = 0$$

**(3) 证明第二方程形式及穿透深度 $\lambda_L$**
令方程 (2) 括号内恒等于 0（London假设条件），得到 London 第二方程$$\nabla \times \vec{J}_s = -\frac{n_s^* e^{*2}}{m^*} \vec{B}$$利用安培定律 $\nabla \times \vec{B} = \mu_0 \vec{J}_s$ (静场忽略位移电流)，两边取旋度
$$\nabla \times (\nabla \times \vec{B}) = \mu_0 (\nabla \times \vec{J}_s)$$
应用矢量恒等式 $\nabla \times (\nabla \times \vec{B}) = \nabla(\nabla \cdot \vec{B}) - \nabla^2 \vec{B}$。由高斯磁定律 $\nabla \cdot \vec{B} = 0$，左侧变为 $-\nabla^2 \vec{B}$，
$$-\nabla^2 \vec{B} = \mu_0 \left( -\frac{n_s^* e^{*2}}{m^*} \vec{B} \right) \implies \nabla^2 \vec{B} = \frac{\mu_0 n_s^* e^{*2}}{m^*} \vec{B}$$
令 $\dfrac{1}{\lambda_L^2} = \dfrac{\mu_0 n_s^* e^{*2}}{m^*}$，即得 $$\nabla^2 \vec{B} = \frac{\vec{B}}{\lambda_L^2}$$其中，London穿透深度 $\lambda_L = \sqrt{\frac{m^*}{\mu_0 n_s^* e^{*2}}}$。

**(4) 内部磁场分布 $\vec{B}(x)$**
一维情况下方程化简为常系数线性齐次微分方程
$$\frac{d^2 B_z}{dx^2} - \frac{1}{\lambda_L^2} B_z = 0$$
其通解为 $$B_z(x) = C_1 e^{x/\lambda_L} + C_2 e^{-x/\lambda_L}$$
基于物理边界条件，当 $x \to \infty$ 时磁场不能发散，故 $C_1 = 0$。在 $x=0$ 边界处与外场连续 $B_z(0) = B_0$，得 $C_2 = B_0$
故分布为$$\vec{B}(x) = B_0 e^{-x/\lambda_L} \hat{z}$$

## 第六题

一电荷量为 $+Q$、半径为 $R$ 的均匀带电球壳以角速度 $\omega$ 匀速转动，已知球壳内部的磁场均匀，等于球心处的磁感应强度，球壳外部磁场与等效的球心处的磁矩产生的磁场相同。
(1) 求球内外的磁感应强度；
(2) 求球壳的自能，并由此求出自感系数；
(3) 设角速度 $\omega(t)=kt$ 缓慢增加，求球内外的涡旋电场；
(4) 求球外能流密度。

【解答】

**(1) 求球内外磁感应强度**
球面电荷密度 $\sigma = \frac{Q}{4\pi R^2}$。转动引起的表面面电流密度 $\vec{K} = \sigma \omega R \sin\theta \hat{\phi}$。
* **内部磁场**（均匀）:
    $$\vec{B}_{in} = \frac{2}{3}\mu_0 \sigma \omega R \hat{z} = \frac{2}{3}\mu_0 \left(\frac{Q}{4\pi R^2}\right) \omega R \hat{z} = \frac{\mu_0 Q \omega}{6\pi R} \hat{z}$$
* **外部磁场**（偶极场，需先计算等效磁矩）:
    $d\vec{m} = \pi (R\sin\theta)^2 K \cdot R d\theta = \pi R^2 \sin^2\theta \cdot (\sigma \omega R \sin\theta) \cdot R d\theta = \pi \sigma \omega R^4 \sin^3\theta d\theta$。积分得 $m = \frac{1}{3}QR^2\omega$。
    $$\vec{B}_{out} = \frac{\mu_0 Q R^2 \omega}{12\pi r^3} \left[ 3(\hat{z} \cdot \hat{r})\hat{r} - \hat{z} \right] = \frac{\mu_0 Q R^2 \omega}{12\pi r^3} (2\cos\theta \hat{r} + \sin\theta \hat{\theta})$$

**(2) 球壳自能与自感系数**
磁场总能量 $W_m = \int \frac{B^2}{2\mu_0} dV$
* 内部$$W_{in} = \frac{1}{2\mu_0} \left( \frac{\mu_0 Q \omega}{6\pi R} \right)^2 \left( \frac{4}{3}\pi R^3 \right) = \frac{\mu_0 Q^2 \omega^2 R}{54\pi}$$
* 外部 $$B_{out}^2 = \left( \frac{\mu_0 Q R^2 \omega}{12\pi r^3} \right)^2 (4\cos^2\theta + \sin^2\theta) = \left( \frac{\mu_0 Q R^2 \omega}{12\pi r^3} \right)^2 (3\cos^2\theta + 1)\Longrightarrow W_{out} = \frac{\mu_0 Q^2 \omega^2 R}{108\pi}$$
总能量 $$W_m = W_{in} + W_{out} = \frac{\mu_0 Q^2 \omega^2 R}{36\pi}$$
旋转带电体的等效电流定义为 $$I = \int_0^\pi \sigma \omega R^2 \sin\theta d\theta = \frac{Q\omega}{2\pi}$$
利用磁能公式 $W_m = \frac{1}{2} L I^2$
$$\frac{\mu_0 Q^2 \omega^2 R}{36\pi} = \frac{1}{2} L \left( \frac{Q\omega}{2\pi} \right)^2 \implies L = \frac{2\pi\mu_0 R}{9}$$

**(3) 涡旋电场计算**
当 $\omega(t) = kt$ 时，利用法拉第定律的积分形式 $\oint \vec{E} \cdot d\vec{l} = -\frac{d\Phi_m}{dt}$。
* **球内涡旋电场:** 取垂直于 $z$ 轴，半径为 $r\sin\theta$ 的安培环路。
    $E_{\phi} \cdot 2\pi r\sin\theta = - \frac{\partial B_{in}}{\partial t} \pi (r\sin\theta)^2 = - \frac{\mu_0 Q k}{6\pi R} \pi r^2 \sin^2\theta$
    解得 $\vec{E}_{in} = -\frac{\mu_0 Q k r \sin\theta}{12\pi R} \hat{\phi}$
* **球外涡旋电场:** 使用库伦规范下的矢势 $\vec{A}_{out} = \frac{\mu_0}{4\pi r^2} \vec{m} \times \hat{r} = \frac{\mu_0 Q R^2 k t \sin\theta}{12\pi r^2} \hat{\phi}$。
    $\vec{E}_{out} = -\frac{\partial \vec{A}_{out}}{\partial t} = -\frac{\mu_0 Q R^2 k \sin\theta}{12\pi r^2} \hat{\phi}$

**(4) 球外能流密度**
能流密度 (Poynting Vector) 为 $\vec{S} = \frac{1}{\mu_0} \vec{E}_{out} \times \vec{B}_{out}$。
代入外场表达式，进行矢量叉乘运算 $(-\hat{\phi}) \times (B_r \hat{r} + B_\theta \hat{\theta}) = -B_r \hat{\theta} + B_\theta \hat{r}$
$$\vec{S} = \frac{1}{\mu_0} \left( \frac{\mu_0 Q R^2 k \sin\theta}{12\pi r^2} \right) \left( \frac{\mu_0 Q R^2 \omega}{12\pi r^3} \right) \left[ \sin\theta \hat{r} - 2\cos\theta \hat{\theta} \right]$$
化简即得
$$\vec{S} = \frac{\mu_0 Q^2 R^4 k \omega \sin\theta}{144\pi^2 r^5} \left( \sin\theta \hat{r} - 2\cos\theta \hat{\theta} \right)$$
