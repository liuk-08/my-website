# 2026春 热学（A）免修考试

考试时间：2026年3月9日

**说明：** 本试卷为回忆版，题目表述和数据与原卷严重不符，仅供参考。

## 一、简答题

### 1
在节流过程中，液体会部分汽化，温度降低。但温度降低意味着液体更冷，为什么反而会汽化呢？

【答】
节流过程是等焓过程。流体通过节流阀后压强骤降，若此时压强低于该温度下的饱和蒸气压，液体将处于过热状态而自发汽化。由于过程绝热，汽化所需的潜热只能由系统内能提供，导致系统内能下降，宏观表现为温度降低。

### 2
玻义耳做实验，探究单摆运动衰减的速度与气压的关系，他使用真空泵抽气会发现什么现象，为什么？进一步，如果他有抽真空效果足够好的真空泵，他能得到阻尼率吗？为什么？

【答】
1. **现象及原因：** 衰减变慢。抽气使气压降低、气体密度减小，单摆受到的空气粘滞阻力减小。
2. **能否得到阻尼率：** 能。即使在极限真空（$p \to 0$，空气阻力消失）下，系统仍存在悬点处的机械摩擦以及悬线内部的弹性滞后（内摩擦）。这些固有耗散机制会使单摆继续衰减，测得的即为系统的固有阻尼率。

## 二、计算与证明

### 3
某范德瓦尔斯气体（总粒子数为 $N$），被一个固定隔板困在占绝热容器总体积 $V_0$ 的 $1/3$ 的空间内，初始温度 $T_i$。在隔板上开一个孔，气体自由膨胀，一段时间后，占据整个容器。已知气体等体热容 $C_V = \frac{3}{2} k N$，求温度和熵的变化。

【解】
绝热自由膨胀过程 $Q=0, W=0$，系统内能守恒 $U_i = U_f$。
根据范氏气体内能 $U = C_V T - \dfrac{a N^2}{V}$：
$$C_V(T_f - T_i) - aN^2\left(\frac{1}{V_f} - \frac{1}{V_i}\right) = 0$$
代入 $V_i = V_0/3, V_f = V_0$ 及 $C_V = \frac{3}{2}kN$：
$$\Delta T = T_f - T_i = \frac{aN^2}{C_V}\left(\frac{1}{V_0} - \frac{3}{V_0}\right) = -\frac{4aN}{3kV_0}$$
由热力学基本方程求熵变：
$$dS = \frac{dU + pdV}{T} = C_V \frac{dT}{T} + N k \frac{dV}{V - Nb}$$
积分得：
$$\Delta S = C_V \ln\left(\frac{T_f}{T_i}\right) + N k \ln\left(\frac{V_f - Nb}{V_i - Nb}\right) = \frac{3}{2} N k \ln\left(1 - \frac{4 a N}{3 k V_0 T_i}\right) + N k \ln\left(\frac{V_0 - Nb}{\frac{1}{3}V_0 - Nb}\right)$$

### 4
（1）两种气体，被固定隔板隔开，摩尔数均为 $\nu$，压强均为 $p$，温度分别为 $T_1$ 和 $T_2$，体积分别为 $V_1$ 和 $V_2$。计算两者分别以两种方式（热接触、联通混合）混合后的熵变。（2）如果是同种气体，结果又是怎样的？

【解】
利用理想气体熵公式$S = \nu C_{V,m} \ln T + \nu R \ln v + S_0$。混合后总摩尔数为 $2\nu$，由热力学第一定律
$$
0=\Delta U=\nu C_{V,m}(T_f-T_1)+\nu C_{V,m}(T_f-T_2)
$$
末温 $$T_f = \frac{T_1 + T_2}{2}$$由初始态知 $$v_1 = \frac{RT_1}{p}, v_2 = \frac{RT_2}{p}$$
**(1) 异种气体**
* **热接触（不混合，体积不变）：**
$$\Delta S_{热} = \nu C_{V,m} \ln\left(\frac{T_f}{T_1}\right) + \nu C_{V,m} \ln\left(\frac{T_f}{T_2}\right) = \nu C_{V,m} \ln\left[ \frac{(T_1 + T_2)^2}{4 T_1 T_2} \right]$$
* **联通混合（热传导+互相向真空自由膨胀）：**
膨胀至总体积 $V_f = V_1 + V_2$，比容 $v_f = v_1 + v_2$
$$\Delta S_{混} = \Delta S_{热} + \nu R \ln\left(\frac{v_f}{v_1}\right) + \nu R \ln\left(\frac{v_f}{v_2}\right) = \nu C_{p,m} \ln\left[ \frac{(T_1 + T_2)^2}{4 T_1 T_2} \right] + 2\nu R \ln 2$$

**(2) 同种气体**
* **热接触：** 结果与异种气体相同
$$\Delta S_{热} = \nu C_{V,m} \ln\left[ \frac{(T_1 + T_2)^2}{4 T_1 T_2} \right]$$
* **联通混合：** 混合后系统同处一个热力学态，总摩尔数为 $2\nu$，末压 $p_f = p$，末态摩尔体积 $$v_f = \frac{V_1+V_2}{2\nu} = \frac{R T_f}{p}$$
末态总熵$$S_f = 2\nu C_{V,m} \ln T_f + 2\nu R \ln v_f + 2\nu S_0$$
始态总熵$$S_i = (\nu C_{V,m} \ln(T_1) + \nu R \ln(v_1) + \nu S_0)+(\nu C_{V,m} \ln(T_2) + \nu R \ln(v_2) + \nu S_0)$$

熵变
$$\Delta S_{同,混} = S_f - S_i = \nu (C_{V,m} + R) \ln\left( \frac{T_f^2}{T_1 T_2} \right) = \nu C_{p,m} \ln\left[ \frac{(T_1 + T_2)^2}{4 T_1 T_2} \right]$$
### 5
自旋导致的铁磁介质的热容近似为 $C(T)$ 方程，求常数 $C_1$。

【解】
系统含 $N$ 个独立自旋（$\pm 1/2$），极高温下完全无序，微观状态数 $\Omega = 2^N$。由热力学第三定律 $S(0)=0$，高温极限总熵为
$$S(\infty) = k \ln(2^N) = N k \ln 2$$
利用熵与热容关系 $\Delta S = \int \frac{C(T)}{T} dT$，得到
$$\int_{T_1/2}^{T_1} \frac{C_1 \left( \frac{2T}{T_1} - 1 \right)}{T} dT = N k \ln 2$$
$$C_1 \left[ \frac{2}{T_1} T - \ln T \right]_{T_1/2}^{T_1} = C_1(1 - \ln 2) = N k \ln 2$$
解得
$$C_1 = \frac{\ln 2}{1 - \ln 2} N k$$

### 6
简谐振子的运动方程为 $x(t) = x_0 \sin(\omega t + \varphi)$，其中 $\varphi$ 在 $[0, 2\pi)$ 上均匀分布。求概率密度函数 $f(x)$。

【解】
振子速度 $v(x) = \omega \sqrt{x_0^2 - x^2}$。
在区间 $[x, x+dx]$ 内，一个周期 $T_0 = 2\pi/\omega$ 内往返各经过一次，总停留时间为 $2dt = 2 \frac{dx}{|v(x)|}$。
概率密度正比于停留时间
$$f(x)dx = \frac{2dt}{T_0} = \frac{2 dx / (\omega \sqrt{x_0^2 - x^2})}{2\pi/\omega} = \frac{dx}{\pi \sqrt{x_0^2 - x^2}}$$
故概率密度函数为
$$f(x) = \begin{cases} \dfrac{1}{\pi \sqrt{x_0^2 - x^2}}, & |x| < x_0 \\ 0, & |x| \ge x_0 \end{cases}$$

### 7
两容器分别装着气体 A 和 B，位于容器 C 的两侧。气体 A 的温度为 $300\ \mathrm{K}$，气体 B 的温度为气体 A 的两倍，气体 B 的粒子数密度是气体 A 的粒子数密度的两倍。在两容器上开面积相同的小孔，使气体泄流进入容器 C。一段时间后，容器 C 中出现了气体 A 的结晶。已知气体 A 的饱和蒸气压方程为
$$\lg(p) = -\frac{7000}{T} + 8.5$$式中气压 $p$ 的单位为 $\mathrm{Pa}$，温度 $T$ 的单位为 $\mathrm{K}$。求此时容器 C 中气体 B 的分压。


【解】
根据气体动理论，单位时间通过单位面积小孔的泄流粒子数为 $\Gamma = \frac{1}{4}n\bar{v}$。 代入平均热运动速度 $\bar{v} = \sqrt{\dfrac{8kT}{\pi m}}$ 与分子数密度 $n = \dfrac{p}{kT}$，泄流公式变为
$$\Gamma = \frac{1}{4} \cdot \frac{p}{kT} \cdot \sqrt{\frac{8kT}{\pi m}} = \frac{p}{\sqrt{2\pi m k T}}$$ 当系统达到动态平衡时，向内与向外的泄流流强相等（$\Gamma_{入} = \Gamma_{出}$）。 对于气体 B，其在容器 C 中建立平衡后满足
$$\frac{p_{B,源}}{\sqrt{2\pi m_B k T_B}} = \frac{p_{B,C}}{\sqrt{2\pi m_B k T_C}} \implies p_{B,C} = p_{B,源} \sqrt{\frac{T_C}{T_B}}$$ 对于气体 A，在结晶出现的临界状态下，气相 A 同样处于泄流平衡状态
$$\frac{p_{A,源}}{\sqrt{2\pi m_A k T_A}} = \frac{p_{A,C}}{\sqrt{2\pi m_A k T_C}} \implies p_{A,C} = p_{A,源} \sqrt{\frac{T_C}{T_A}}$$ 两式相除，消去未知的容器 C 的温度 $T_C$ 得到
$$\frac{p_{B,C}}{p_{A,C}} = \frac{p_{B,源}}{p_{A,源}} \sqrt{\frac{T_A}{T_B}}$$ 根据理想气体状态方程 $p=nkT$ 及已知源端条件（$n_B = 2n_A, T_B = 2T_A$）
$$\frac{p_{B,源}}{p_{A,源}} = \frac{n_B k T_B}{n_A k T_A} = 2 \times 2 = 4$$ 代入上式求得压强比值关系
$$\frac{p_{B,C}}{p_{A,C}} = 4 \times \sqrt{\frac{1}{2}} = 2\sqrt{2}$$ 依题意，C 容器中 A 出现结晶，说明 A 达到了当前温度下的饱和蒸气压。
取标准考题设定 $T_C = T_A = 300\ \mathrm{K}$。
$$\lg(p_{A,C}) = -\frac{7000}{300} + 8.5 = -14.833 \implies p_{A,C} = 10^{-14.833}\ \mathrm{Pa}$$ 最终解得气体 B 的分压为
$$p_{B,C} = 2\sqrt{2} p_{A,C} \approx 2.828 \times 1.47 \times 10^{-15}\ \mathrm{Pa} \approx 4.16 \times 10^{-15}\ \mathrm{Pa}$$
### 8
实验测定，冰和水的饱和蒸气压方程分别为 

$$\ln p_\text{固} = 28.916 - \dfrac{6140.4}{T}$$和
$$\ln p_\text{液} = 25.525 - \dfrac{5419.3}{T}$$
（式中气压 $p$ 的单位为 $\mathrm{Pa}$，温度 $T$ 的单位为 $\mathrm{K}$）。求三相点与相变热。

【解】
**(1) 三相点温度与压强**
三相点处 $p_{固} = p_{液}$
$$28.916 - \frac{6140.4}{T_t} = 25.525 - \frac{5419.3}{T_t}\implies T_t \approx 272.69\ \mathrm{K}$$
代入得压强
$$p_t = \exp\left(25.525 - \frac{5419.3}{272.69}\right) \approx 284.85\ \mathrm{Pa}$$

**(2) 相变热**
由克劳修斯-克拉佩龙方程积分式 $\ln p = A - \frac{L}{RT}$，可知方程中 $1/T$ 的系数为 $-L/R$。
汽化热  $L_\text{汽} = 5419.3 \times 8.314 \approx 45056\ \mathrm{J/mol} = 45.06\ \mathrm{kJ/mol}$
升华热  $L_\text{升} = 6140.4 \times 8.314 \approx 51051\ \mathrm{J/mol} = 51.05\ \mathrm{kJ/mol}$
溶解热  $L_\text{融} = L_\text{升} - L_\text{汽} = 5.99\ \mathrm{kJ/mol}$
